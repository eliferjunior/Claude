When explaining code ($ARGUMENTS):

1. **Start with an analogy** - Compare the code to a real-world concept
2. **High-level overview** - What does this code do in 1-2 sentences?
3. **Step-by-step walkthrough** - Go through the code line by line
4. **Data flow** - Describe how data moves through the code
5. **Key concepts** - Highlight patterns, algorithms, or techniques used
6. **Gotchas** - Point out potential issues or tricky parts
7. **Improvements** - Suggest possible improvements if applicable
